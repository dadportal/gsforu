# gsforu

**Generate your full stack. Own every line. Ship under your name.**

Most AI tools build apps *for* you.  
gsforu helps you **generate real, exportable code** you fully control — so you can rebuild, customize, and release it as your own product.

## Live Site

After deploying to Vercel, your site will be live at your Vercel URL.

## Local Development

Just open `index.html` in your browser, or serve it with any static server.

```bash
npx serve .
```

## Deploy to Vercel

1. Go to [vercel.com](https://vercel.com)
2. Import this GitHub repository
3. Deploy (zero config needed)
